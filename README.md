# 🎥 VidFetch Ultra 极客自研全平台视频下载与 AI 提炼系统

这是一个由 Node.js 后端与 Vue 3 + Vite 前端共同构建的**全栈视频解析与文字提炼系统**。支持抖音（无水印、无片尾）、B站（含原生 AI 语音字幕提取）、小红书、TikTok 等平台。

---

## 📂 项目结构说明

本工程采用前后台分离的经典全栈设计：
* **根目录 `/` (后端)**：基于 Express + Puppeteer 的无头浏览器网络层嗅探引擎。
* **`/frontend` (前端)**：基于 Vue 3 + Vite 的玻璃态 Bento 设计前台。

---

## 🚀 极速运行指南

### 1. 启动前准备 (安装依赖)
本工程推荐使用 `pnpm` 作为包管理器（亦支持 `npm` 或 `yarn`）。在首次运行前，需要分别安装前端与后端的依赖包：

```bash
# 步骤 1：在【根目录】下安装后端依赖
pnpm install

# 步骤 2：进入【frontend目录】安装前端依赖
cd frontend
pnpm install

# 步骤 3：返回【根目录】准备启动
cd ..
```

---

### 2. 一键启动项目（推荐）
你**不需要**开两个终端分别运行，我们在根目录的 `package.json` 中内置了并行运行脚本。

在 **【项目根目录】** 下，直接执行以下一键启动命令：

```bash
pnpm dev
# 或者使用 npm / yarn:
# npm run dev
# yarn dev
```

该命令会同时唤起：
* **后端 API 服务** ── 运行在 `http://localhost:3000`
* **前端 Vite 服务** ── 运行在 `http://localhost:5173`

启动成功后，直接在浏览器中打开 **`http://localhost:5173/`** 即可完美体验！

---

## ⚙️ 接入豆包 AI 大模型说明

本系统支持深度智能提取与总结视频文案：
1. 打开浏览器 `http://localhost:5173/`。
2. 点击顶部 Logo 旁边的 **⚙️ (齿轮设置)** 按钮。
3. 开启豆包 API 选项，填入你从火山引擎官方申请的 **API Key** 以及在线推理中创建的 **推理接入点 ID (Endpoint ID, 以 ep- 开头)** 并保存。
4. 亦可直接在后端代码 `server.js` 约 366-368 行进行**硬编码默认值填写**，方便一劳永逸使用。

## 🛡️ 极客功能亮点
* **无水印去片尾**：抖音视频在下载时会自动通过后端代理重映射，强行切除水印并自动裁掉末尾的 3 秒片尾宣传画面。
* **原生字幕提取**：针对 B站 视频，能在 Puppeteer 内部沙箱中绕过 CORS 直接拉取其 AI 语音字幕，拼接成最原汁原味的视频文案。
* **防盗链流式下载**：所有视频下载请求全部经由后端 Node.js 进行流式（Pipe）代理中转，伪造 Referer 报头以绝无报错地保存到本地。
