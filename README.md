# 🎥 VidFetch Ultra 极客自研全平台视频下载与 AI 提炼系统

这是一个由 Node.js 后端与 Vue 3 + Vite 前端共同构建的**企业级全栈视频解析与文字提炼系统**。支持抖音（无水印、无片尾）、B站（含原生 AI 语音字幕提取）、小红书、TikTok、YouTube 等主流平台，深度集成 ASR 语音识别与主流大语言模型。

---

## 📂 项目结构说明

本工程采用前后端分离的设计：
* **根目录 `/` (后端)**：基于 Express + Puppeteer 的无头浏览器网络层嗅探与代理下载引擎。
* **`/frontend` (前端)**：基于 Vue 3 + Vite 的玻璃态 Bento 设计控制台。

---

## 🚀 极速运行指南

### 1. 启动前准备 (安装依赖)
本工程推荐使用 `pnpm` 作为包管理器（亦支持 `npm` 或 `yarn`）。在首次运行前，需要分别安装前端与后端的依赖包：

```bash
# 步骤 1：在【根目录】下安装后端依赖
pnpm install

# 步骤 2：进入【frontend目录】安装前端依赖
cd frontend
pnpm install

# 步骤 3：返回【根目录】准备启动
cd ..
```

---

### 2. 一键启动项目（推荐）
在 **【项目根目录】** 下，直接执行以下一键启动命令即可并行运行前后端：

```bash
pnpm dev
# 或者使用 npm / yarn:
# npm run dev
# yarn dev
```

该命令会同时启动：
* **后端 API 服务** ── 运行在 `http://localhost:3000`
* **前端 Vite 服务** ── 运行在 `http://localhost:5173`

启动成功后，直接在浏览器中打开 **`http://localhost:5173/`** 即可完美体验！

## ⚙️ 核心配置与大模型说明

### 1. 豆包 AI & 硅基流动大模型
本系统支持深度智能提取与总结视频文案：
* 点击顶部 Logo 旁边的 **⚙️ (齿轮设置)** 按钮。
* 开启豆包 API 选项，填入您从火山引擎官方申请的 **API Key** 以及在线推理中创建的 **推理接入点 ID (Endpoint ID)**。
* 亦可配置硅基流动 (SiliconFlow) 等 OpenAI 兼容大模型节点及 SenseVoice 语音识别 ASR 服务。

### 2. SMTP 邮箱验证配置 (管理员)
系统内置完备的邮箱注册与密码找回逻辑：
* 管理员登录后台后可在后台配置 SMTP 服务器（如网易 163、QQ 邮箱等），配置授权码（SMTP Pass）即可开启全站真实邮箱验证码发送。
* 若未配置 SMTP，验证码将安全降级输出于 Node.js 服务端的控制台终端。

## 🛡️ 极客特色功能与安全性

### 1. 核心嗅探下载优势
* **无水印去片尾**：抖音视频在下载时会自动通过后端代理重映射，强行切除水印并自动裁掉末尾的 3 秒片尾宣传画面。
* **原生字幕提取**：针对 B站 视频，能在 Puppeteer 内部沙箱中绕过 CORS 直接拉取其 AI 语音字幕，拼接成最原汁原味的视频文案。
* **防盗链流式下载**：所有视频下载请求全部经由后端 Node.js 进行流式（Pipe）代理中转，伪造/擦除 Referer 报头以绝无报错地保存到本地。

### 2. 账号与个人资料管理
* **安全邮箱注册与登录**：支持图形验证码校验，防御人机接口轰炸。注册时支持邮箱验证码验证，且同一邮箱/IP一分钟内限制获取一次。
* **个人资料 & 简介**：支持修改昵称、个人简介（bio）以及更新头像种子。为了防止泄露隐私，用户邮箱地址将进行前三位及后缀脱敏加密展示（例如 `123***@qq.com`），且头像生成采用安全的随机种子。
* **修改登录密码**：支持双轨修改模式：(1) 输入原密码修改；(2) 在忘记原密码时，通过绑定的安全邮箱发送验证码重置。

### 3. 系统管理员后台（Admin Dashboard）
* **账号全生命周期管理**：系统内置对 `mediaAdmin` 和 `mediaSuper` 的内置保护。支持管理员创建、删除普通账号以及升级超级用户。
* **用户详情查看 (User Inspector)**：支持点击“查看”按钮查看每个用户的头像、角色、账号名、简介、以及今日额度消耗详情。
* **5 字段多维度日志筛选**：审计日志面板支持**操作时间范围 (起止区间)、账号名、用户昵称、操作动作、提取链接** 5 个字段的多维度多条件联合筛选，并提供“查看历史日志”和“查看今日筛选日志”的快速跳转一键筛选入口。
